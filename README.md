# Avea Solutions

Premium managed staffing landing page for Australian law firms and professional practices.

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Brand

Colors: `#EBEBE3`, `#05577C`, `#028790`, `#FFFFFF`, `#000000`  
Type: Montserrat (UI) + Bebas Neue as display stand-in for Morise until font files are provided.  
Tagline: The Right People. The Right Fit.
